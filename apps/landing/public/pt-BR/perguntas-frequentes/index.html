FAQ

Perguntas antes de instalar.

Quanto o Standcast custa, o que ele lê, do que ele precisa e quem vê o quê.

Suporte

Ainda tem alguma dúvida?

Escreva para support@standcast.app ou leia a documentação.

É grátis?

Sim, durante o beta público.

Quanto vai custar depois do beta?

Os preços serão anunciados antes do fim do beta público.

O Standcast lê o nosso código?

Não. O GitHub App lê pull requests, reviews, checks, metadados de commits, o standcast.yml e o CODEOWNERS. Ele nunca lê arquivos de código.

Do que eu preciso?

Uma organização ou conta pessoal no GitHub, e um workspace no Slack ou o Google Chat do Google Workspace. O Linear é opcional. Jira, ClickUp, Asana, GitHub Projects, Microsoft Teams e Discord vêm a seguir e ainda não estão conectados.

Com quais agentes eu escrevo a minha daily?

Claude Code, Cursor, Codex, Claude Desktop e VS Code, pelo plugin do Claude Code ou pelo servidor MCP local. O terminal também funciona.

O meu gestor vê os impedimentos sugeridos para mim?

Não. As sugestões aparecem só para você, no seu rascunho. Elas nunca chegam ao consolidado, à API, aos webhooks nem aos gestores.

O Standcast pode enviar uma daily por mim?

Não. A tool de envio do MCP exige confirmed: true, que o agente só passa depois que você aprova o texto.

Dá para hospedar por conta própria?

Sim. O Standcast tem licença MIT. A seção de self-hosting do README cobre a API, o worker e o Postgres.

Beta público

Teste com o seu time.

Procuramos times de 3 a 15 pessoas que usam GitHub e Slack ou Google Chat. Ajudamos você a configurar.
