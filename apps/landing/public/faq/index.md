# FAQ

> Questions before you install. What Standcast costs, what it reads, what it needs and who sees what.

## Is it free?

Yes, during the public beta.

## How much will it cost after the beta?

Pricing will be announced before the public beta ends.

## Does Standcast read our code?

No. The GitHub App reads pull requests, reviews, checks, commit metadata, standcast.yml and CODEOWNERS. It never reads source files.

## What do I need?

A GitHub organization or personal account, and a Slack workspace or Google Chat in Google Workspace. Linear is optional. Jira is in development.

## Which agents can I write my daily with?

Claude Code, Cursor, Codex, Claude Desktop and VS Code, through the Claude Code plugin or the local MCP server. The terminal works too.

## Can my manager see my suggested blockers?

No. Suggestions are visible only to you, in your own draft. They never reach the digest, the API, webhooks or managers.

## Can Standcast send a daily for me?

No. The MCP submit tool needs `confirmed: true`, which the agent passes only after you approve the text.

## Can we self-host?

Yes. Standcast is MIT licensed. The [self-hosting section of the README](https://github.com/ImFelipeOliveira/standcast#self-hosting) covers the API, the worker and Postgres.

## Still have a question?

Write to support.standcast@usefachada.dev or read the [documentation](https://docs-standcast.usefachada.dev/).
